# ICS Converter

Консольная утилита для преобразования календарей `.ics` в Markdown или обычный текст. Подходит для сохранения расписаний и списков событий в удобном для чтения виде.

Для каждого события сохраняются название, начало и окончание, место, организатор и описание, если эти поля заполнены. События сортируются по дате начала, события без даты помещаются в конец списка. Результат записывается в UTF-8.

## Установка

Требуется Python 3.14 или новее. Выполните команды из корня проекта.

С помощью [uv](https://docs.astral.sh/uv/):

```bash
uv sync --locked
```

Или установите пакет через pip в виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
```

## Использование

Преобразовать календарь в Markdown:

```bash
uv run ics-converter "Расписание.ics"
```

Рядом с исходным файлом появится `Расписание.md`.

Выбрать текстовый формат:

```bash
uv run ics-converter "Расписание.ics" --format txt
```

Указать путь к результату:

```bash
uv run ics-converter "Расписание.ics" -f md -o "Календарь.md"
```

После установки через pip используйте те же команды без префикса `uv run`.

| Аргумент | Назначение |
| --- | --- |
| `input` | Путь к исходному файлу с расширением `.ics` |
| `-f`, `--format` | Формат результата: `md` (по умолчанию) или `txt` |
| `-o`, `--output` | Путь к результату; по умолчанию используется путь исходного файла с новым расширением |
| `-h`, `--help` | Справка по команде |

Формат содержимого задаётся параметром `--format`, независимо от расширения выходного файла. Родительский каталог результата должен существовать. Существующий выходной файл перезаписывается; совпадение путей входного и выходного файлов запрещено.

## Пример Markdown

```markdown
# 📅 Календарь событий

## Встреча команды

**Начало:** 16.11.2026 10:00
**Окончание:** 16.11.2026 11:00
**Место:** Переговорная

### Описание

Обсуждение планов на неделю.

---
```

## Особенности

- Повторяющиеся события (`RRULE`) не разворачиваются в отдельные даты: каждый компонент `VEVENT` выводится один раз.
- Время выводится в том виде, в котором оно прочитано из календаря, без перевода в локальный часовой пояс и без указания смещения в результате.
- Для событий на весь день выводится только дата. Дата окончания берётся из `DTEND` без изменений.
- Смешение событий с датой без времени и событий с датой и временем, а также дат со смещением часового пояса и без него может вызвать ошибку сортировки.
